Recursive Algorithm
function hanoi(n, source, auxiliary, target):
    if n == 1:
        move disk 1 from source to target
    else:
        hanoi(n-1, source, target, auxiliary)
        move disk n from source to target
        hanoi(n-1, auxiliary, source, target)
How to Play
  • Select disk count (this sets the level).
  • Click pegs to move the top disk (obey the rules!).
  • Use SOLVE to auto-animate or STEP to go one move at a time.
  • RESET restarts with the current disk count.
  • Win to earn points! Level 1 = +5, Level 2 = +10, etc.
Rules
  1. Move only one disk at a time.
  2. No larger disk on top of a smaller disk.
